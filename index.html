🔥 Petunjuk Setup Firebase Firestore Gratis

Aplikasi ini sudah siap terhubung ke Firebase Firestore secara gratis. Langkah singkat memasukkan kunci API:

  1. Buka website console.firebase.google.com.
  2. Buat proyek baru & tambahkan aplikasi Web (ikon </>).
  3. Salin kode firebaseConfig yang diberikan.
  4. Buka file index.html ini di editor/GitHub, dan tempelkan pada variabel di bagian paling atas script JS.
  5. Aktifkan Firestore Database di mode Test Mode. Selesai!

ℹ️ Jika config belum diisi, aplikasi otomatis memakai mode LocalStorage agar tetap bisa dites offline!
